# NKK YB / YB2シリーズ 型番コンフィギュレータ（非公式）

NKKスイッチズの照光式押ボタンスイッチ **YBシリーズ／YB2シリーズ** のオーダー形名を、仕様を選ぶだけで組み立てられるWebツールです。型番を入力して仕様を確認する**逆引き**にも対応しています。

**▶ デモ： https://celestial-globe.github.io/NKK_SW_configurator/**

## できること

- 回路・機能動作・防水・取付け・形状・接点・照光方式・発光色・電圧・ボタン色を選ぶと、オーダー形名（例: `YB-15WSKS1-119BBS`、`YB2-15CWCKS1-61MGNS`）をリアルタイム生成
- スイッチ本体・発光素子（AT-611／621／625／628／631／632／634／636）・操作部ボタンの**個別形名**も同時に表示（部品バラ手配用）
- カタログ規定の組み合わせルールを自動チェック（防水形はねじ取付けのみ、プレート色はLED同色か乳白のみ、など）。不正な組み合わせは選択できません
- **逆引き**: オーダー形名または本体形名を入力すると仕様を解読して選択肢に展開。全角・小文字・スペース混じりの入力も正規化します
- 形名の桁ごとの意味の分解表示、抵抗なしLEDの制限抵抗計算式（VF/IF値付き）などの注意事項表示
- 単一HTMLファイルのみ・外部通信なし・オフライン動作可

## 対応シリーズ

| シリーズ | 概要 |
|---|---|
| YB | 短胴形・φ16取付け（防水形／非防水形、丸・角・長角、白熱球／LED／2色発光／部分照光） |
| YB2 | 業界最薄クラス防水形・φ22／□21取付け（ハーフミラー・外輪照光・非照光ボタン、黒／ステンレス調フランジ。旧シルバー記号Sの逆引きにも対応） |
